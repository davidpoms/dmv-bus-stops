# DMV Bus Stops Roadmap

## Vision

Move from:

> Finding stops without benches

to:

> Identifying high-demand stops where waiting conditions may not adequately support riders.

---

# Phase 1 — Prototype Stabilization

Status: Current

Goals:

- stabilize Flask API
- stabilize dashboard
- document current data sources
- fix terminology

Changes:

- replace "bench missing" language
- replace "score/impact" language
- introduce evidence-based explanations

---

# Phase 2 — Conceptual Redesign

Goal:

Create a clearer distinction between:

## Evidence

What we know.

Examples:

- shelter exists
- ridership level
- WMATA program status

---

## Observation

What humans see.

Examples:

- seating uncomfortable
- shelter crowded
- accessibility concern

---

## Assessment

What we recommend.

Examples:

- investigate seating capacity
- review accessibility
- no action needed

---

# Phase 3 — Volunteer Review System

Create structured review workflows.

## Remote Review

Volunteers can determine:

- shelter presence
- visible seating
- visible barriers
- obvious issues

Sources:

- Street View
- imagery
- maps

---

## Field Review

Volunteers determine:

- comfort
- actual usability
- crowding
- maintenance
- rider experience

---

# Phase 4 — Better Dashboard

Replace:

Score: 89

Impact: Very High

With:

Example:

> This stop serves many riders. Available information suggests the waiting area may not fully support current demand. Additional review is recommended.

---

# Phase 5 — Agency-Facing Outputs

Generate reports:

Examples:

## Stop Profile

- infrastructure
- evidence
- observations

## Improvement Opportunity

- issue
- supporting evidence
- confidence
- recommended action

---

# Key Research Questions

- How should waiting quality be measured?
- What observations are reproducible?
- How can volunteer evidence complement agency data?
- Which findings would be actionable?

---

# Success Criteria

A successful system should produce:

> A credible list of bus stops where rider demand, infrastructure, and passenger experience appear misaligned.

The project should support:

- transit agencies
- advocates
- communities
- researchers
